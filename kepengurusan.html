✏️ Cara Mengganti Data Halaman Ini

Semua nama & foto di halaman ini diisi otomatis dari js/data.js:

  1. Buka file js/data.js dengan notepad / VS Code.
  2. Cari bagian kepengurusan.
  3. Ubah nama, kelas, atau peran; salin satu blok { ... } untuk menambah anggota.
  4. Untuk foto: upload foto ke Google Drive (akses "siapa saja yang punya link"), lalu tempel link-nya di kolom foto. Jika dikosongkan, inisial nama akan tampil otomatis.
